# Project Video

The project walkthrough (4 min 35 s) is hosted on YouTube:

**https://youtu.be/fQpp9Fr1Up4**

It covers what ROP is and how it is classified, why screening is hard, the preprocessing
pipeline, how the project evolved to the 6-class staging dataset, the EfficientNetV2-S results,
and where the work goes next.

The video was recorded partway through the staging work, so where its numbers and the main
README disagree, the README is current. See the "Project video" note in the main README for the
specifics.
