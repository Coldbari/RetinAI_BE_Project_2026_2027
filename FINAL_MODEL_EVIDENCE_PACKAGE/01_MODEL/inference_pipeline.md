# Inference Pipeline — every transformation, and where it happens

Diagram: [`../04_PREPROCESSING/preprocessing_pipeline.png`](../04_PREPROCESSING/preprocessing_pipeline.png)

```
RAW IMAGE  (JPEG/PNG, native resolution, one acquisition view of one eye)
   │
   │  PIL Image.open(...).convert("RGB")
   │  ── webapp/inference.py  ·  models/common/datasets.py::FundusDataset.__getitem__
   ▼
DATASET LOADER
   │  ⚠ on a read failure FundusDataset returns a BLACK image with the TRUE label,
   │    silently and uncounted. The Kaggle kernel guards this with an os.path.exists
   │    check; nothing in the library does.
   ▼
PREPROCESSING   models/common/preprocessing.py::FundusPreprocess  (single source of truth)
   │  1. circle_crop(tol=7)        crop to bounding box of non-black pixels
   │  2. letterbox_square()        pad to square with black bars — anti-shortcut step
   │  3. clahe(clip=2.0, grid=8)   CLAHE on the L channel of LAB
   │  4. Resize((384, 384))        single isotropic resize
   │  5. ToTensor + Normalize      ImageNet statistics
   │  (ben_graham is OFF for ROP — the signal is vascular/peripheral)
   │  TRAIN ONLY, never at inference: flips · rot15 · colour jitter · hue/sat jitter ·
   │  RandomGrayscale(0.10) · ResolutionJitter · RandomResizedCrop(0.6–1.0)
   ▼
MODEL           models/common/structured.py::StructuredROPModel  (variant "full")
   │  EfficientNetV2-S → flatten → Dropout(0.3) → z ∈ ℝ¹²⁸⁰
   │  → stage_head (CORN, 4 logits) · arop_head (1 logit) · site_head (ignored)
   ▼
PROBABILITY OUTPUT      decode_6class(out, arop_threshold=0.5, variant="full")
   │  prob6 = [(1−pₐ)·P(rank=k) …, pₐ] ; pred6 = 5 if pₐ>0.5 else CORN rank
   ▼
PREDICTION DECODING     ── ONE forward pass. No TTA at serving.
   ▼
VIEW AGGREGATION        ✗ NOT PERFORMED by the model or the app.
   │  Applied only in offline evaluation (scripts/rop_locked_eval.py and this package's
   │  s04). Six rules were compared; the choice changes QWK from 0.35 to 0.85.
   ▼
EYE AGGREGATION         eye = (patient_id, left|right) from the dataset's own
   │  Acquisition View Table. label = max over views; prediction = max over views.
   │  ⚠ offline only — the deployed app scores one photograph at a time and therefore
   │    operates at the WORST-performing unit in this package.
   ▼
PATIENT / SESSION       ✗ not implemented for the external corpus (no session structure).
   │  Session-level aggregation exists for the Ostrava cohort in the parent repository.
   ▼
METRIC CALCULATION      FINAL_MODEL_EVIDENCE_PACKAGE/20_AUDIT/scripts/common.py
      · macro-F1 / accuracy / balanced accuracy / per-class P·R·F1  (scikit-learn)
      · QWK over the FIVE ordinal classes only  (AP-ROP pairs excluded)  ← corrected here
      · unweighted Cohen's κ, multiclass Brier, 15-bin ECE
      · patient-clustered percentile bootstrap for every 95% CI
```

## Where the numbers in this package come from

| stage | artifact |
|---|---|
| internal, 5 folds | `results/rop/staging_runs/structured_5fold/fold_{0..4}.npz` (committed at training time) |
| external dev | `results/rop/dev_eval/structured_s42_ckpt{0..4}.npz` |
| external locked | `results/rop/locked_eval/structured_s42_ckpt{0..4}.npz` (opened once) |
| served-checkpoint re-run | `20_AUDIT/served_checkpoint_dev_rerun.npz` (generated by this package) |
| Grad-CAM | generated fresh by `20_AUDIT/scripts/s08_gradcam.py` |

## Train / serve parity — verified

`webapp/inference.py` loads `configs/rop_staging_structured.yaml` and calls
`build_transforms(cfg, "val")` — the same function, same config, same code path used to
produce the committed evaluation predictions. The served weights were re-run through this
path for this package and matched the committed fold-0 predictions to 3e-06.
**There is no train/serve preprocessing skew in this model.**
