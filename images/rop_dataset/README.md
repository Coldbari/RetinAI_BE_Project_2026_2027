# images/rop_dataset/

The ROP corpus after classification — what we hold, how it is labelled, and what is wrong with
it. All six figures are generated by `scripts/make_dataset_graphs.py` from
`data/rop_classified/MANIFEST.csv`, so re-running `scripts/build_rop_classified.py` and
re-running this script keeps the picture and the number in step. Nothing is hardcoded.

```bash
.venv/bin/python scripts/build_rop_classified.py   # rebuilds the classified tree + manifest
.venv/bin/python scripts/make_dataset_graphs.py    # rebuilds these figures
```

## The figures

| # | File | Answers |
|---|---|---|
| 1 | `01_classification_table.png` | **The classification table.** Images per ICROP class × source dataset, with totals and distinct infants. This is the reference figure — every number in the others comes from here. |
| 2 | `02_class_composition.png` | What each class is *made of*. Proportional, so Stage 0/4/5 stay readable. Shows the single-source dependencies at a glance. |
| 3 | `03_infants_per_class.png` | Infants per class, pooled vs Ostrava alone. **The constraint that actually binds** — Stage 3 went from 2 infants to 404. |
| 4 | `04_held_separate.png` | The 3,394 images held *out* of the stage classes, and why none of them can be given a stage without inventing one. |
| 5 | `05_binary_label_composition.png` | What the current two-class model's "ROP Detected" label really contains — 43% of it is not ROP. |
| 6 | `06_corpus_growth.png` | Before/after per disease class. Normal is omitted so the rest stays legible. |

## What these figures are for

Figures 1–3 are the **dataset description** — the thing to put in front of anyone asking what
the corpus is. Figures 4–6 are the **honest caveats**: what had to be excluded, what the old
label actually was, and how much of the growth is real.

Three things the figures are deliberately built to make hard to miss:

- **Stage 5 is 100% ROP-VL and Stage 4 is 77% ROP-VL** — both from one hospital. Any result on
  those classes is single-site, and figure 2 shows it without needing a footnote.
- **Stage 0 is 100% Ostrava and is not Normal.** ICROP stage 0 is an immature retina without
  ROP; it is 45 images from 4 infants.
- **The old positive class was 43% non-ROP** — hemorrhage, toxoplasma, hamartoms, optic nerve
  hypoplasia (figure 5).

## Design notes

Same conventions as `images/`: dark surface `#1a1a19`, recessive grid, direct labels, 200 dpi.

The six source hues are a new categorical assignment (the parent palette covers three
diseases, not six datasets). They were validated with the dataviz six-check validator against
the dark surface — **all six PASS**, worst adjacent CVD ΔE 8.4 (protan). Gold ↔ aqua sit at
tritan ΔE 4.0, which is inside the floor band, so every segment is **also** direct-labelled
and separated by a surface gap; identity never depends on colour alone.

Figures 2 and 6 were both rebuilt after review: `Normal` is 4,358 of 9,323 images and, on an
absolute scale, squashed every small class into an unreadable sliver. Figure 2 is now
proportional (composition is the question it answers; magnitude lives in figures 1 and 6) and
figure 6 omits `Normal` with its growth stated in the caption instead.
